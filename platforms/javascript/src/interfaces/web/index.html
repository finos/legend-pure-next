Legend Pure — standalone JavaScript compiler & executor

Parses, compiles and runs Pure source entirely in the browser (no JVM). The parser bundle, the compiler JS and the translator JS are the artifacts translation/javascript produces; the metamodel is read from the committed .pdb files by the in-browser PDB reader. Run (or F9) compiles, translates each element to JavaScript in-process, evals it, then calls function go():Any[*]; the compiled graph and the generated JavaScript are shown below the result. Errors are highlighted in the source.
